# P0-13: 同一WASMモジュールのAndroidでの実行

- **調査日:** 2026-11-08
- **状態:** Androidエミュレーター（x86_64）で確認済み。実機（arm64）は未確認。iOSは保留（統合開発計画 §1.2）。
- **目的:** P0-06のWASMモジュールを、ADR-0005のWasmiでAndroid上で実行し、結果がデスクトップと一致することを確認する（実行計画 P0-13の完了条件）。

## 1. 環境

- `nix develop .#android`（ADR-0010の改訂）: Rust 1.99.0（rust-overlay、`x86_64-linux-android` 等）、Android SDK、NDK 28.2.13676358、`cargo-ndk` 4.1.2、エミュレーター 37.2.13。
- エミュレーター: AVD `hisui-api35`（Android 15、API 35、x86_64、Pixel 7の定義）。ウィンドウなし、KVM使用、`-gpu swiftshader_indirect`。
- 実行方法: P0-06のホスト（[`spikes/p0-06-wasm-runtimes/host`](../../spikes/p0-06-wasm-runtimes/host)、Wasmiのみの構成）を `cargo ndk -t x86_64 --platform 35` でビルドし、`adb push` で `/data/local/tmp` に置いて `adb shell` から実行した（APKは作らない）。WASMモジュールと1 MBの文書はデスクトップと同じファイル。

## 2. 結果

| 項目 | デスクトップ（Linux） | Android（エミュレーター） |
|---|---|---|
| 解析のイベント数（ネイティブ・WASMとも） | 149,366 | **149,366** |
| ホスト経由の規則呼び出しの結果（認識した長さの合計） | 191,055 | **191,055** |
| 1 MBの解析で消費した燃料 | 4,079,803,293 | **4,079,803,293** |
| 燃料による停止 | 停止した | 停止した |
| 停止後の同じインスタンスの再利用 | 可 | 可 |
| メモリ上限（64 MiB） | 1,024ページで停止 | 1,024ページで停止 |

- 同じWASMモジュールの実行結果はデスクトップと一致した。**燃料の消費量も完全に一致した**（燃料による時間の上限は、プラットフォームが同じ値で同じ位置で止まる）。
- 参考値（エミュレーター上。実機の性能を表さない）: 1 MBの解析はネイティブ55 ms・Wasmi 約0.4秒、4 KBのブロックはWasmi 約1〜1.7 ms、モジュールの準備は5〜36 ms。

## 3. 追加の確認: ICU4X・Fluent（P0-10）

P0-10の確認プログラム（全機能）をAndroid（x86_64エミュレーター）で実行し、出力（Localeのフォールバック、単語・行の分割、照合、正規化、複数形、数値、日付、Fluent）がLinuxと**バイト単位で一致**した。Android arm64向けのサイズは [`P0-10-i18n.md`](P0-10-i18n.md) に記録した。
